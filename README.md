# Voxel Walk 128 — WebGL2 スプライトスタッキング・ボクセルワールド

> **このリポジトリは Neon を試すために、AIとの対話だけでゼロから作り上げた実験プロジェクトです。**  
> 外部ライブラリ・ビルドツールを一切使わず、純粋な HTML / CSS / JavaScript + WebGL2 だけで 128×128×14 の動的なボクセル世界を描画しています。

## オンラインデモ＆ウォークスルー動画

- **メインアプリ（Voxel Walk 128）**: https://kengonakajima.github.io/stacking/voxel-walk/ （ルート https://kengonakajima.github.io/stacking/ からも自動リダイレクトされます）
- **ウォークスルー動画（YouTube・自動探索撮影＆AI字幕付き）**: https://youtu.be/7FPYQUXml3o
- **初期に作ったシューティングデモ（待避版）**: https://kengonakajima.github.io/stacking/shooting/

ローカルでも `voxel-walk/index.html` をブラウザで直接開くだけで動作します（`file://` 対応・ビルド不要）。

## 主な機能

- **WebGL2 インスタンシング・スプライトスタッキング描画**: 1ブロック = `6×6` ピクセル × `8` スライスの輪切り2Dレイヤーを積み上げて 1:1:1 の立体ボクセル世界を構築。
- **128×128×14 マルチバイオーム地形（毎回ランダムシード）**: 森の渓谷・岩山・オーバーハング・トンネル・スパゲッティ洞窟・山頂の湧き水の泉（6か所）・溶岩だまり（7か所）を生成。
- **リアルタイム破壊＆流体連動**: 画面上の**どんなブロックでも左クリック1回で破壊**でき（デブリなし）、開けた穴へ水や溶岩がすぐ流れ込み、太陽光や松明の光も即座に再計算されます。
- **連続する小川＆多層ノイズの滝**: 山頂の泉から少しずつ水が湧き出し、流路トレイルで途切れない小川と3層異速度ノイズ＋滝壺しぶきの滝を形成。
- **ゆっくり流れる粘性溶岩**: 明るさ15の自己発光マグマが水の約1/4の速度でねっとり流れ、進出先へ16ブロック届く光をリアルタイムに運びます。
- **Minecraft風 16段階3Dライトエンジン＆昼夜サイクル**: 明け方（05:30）から始まり、昼・夕焼け・真っ暗な夜へ移行。松明（`F` 設置 / `X` 回収）からは風になびく煙が立ち上ります。
- **生きている自然演出**: 立方体の形を崩さずブロック単位で揺れる木（体当たりで大きく揺れる）、風になびき歩くと押し分けられる雑草と5色の野花、高さ20を東→西へ流れる `1×1×1` 雲ブロックと連動する雲の影、草原を歩く白い羊モブ（10匹）。
- **完全遮蔽ベースの洞窟透視（X-Ray）**: プレイヤーの頭・胸・足・両肩の5点すべてがカメラ視線から隠れたときだけ、遮蔽ブロックの外表面輪郭だけを残して透視します。

## 操作方法

| 入力 | 動作 |
| --- | --- |
| `W` `A` `S` `D` / `↑↓←→` | 移動 |
| `Space` | 2ブロック登れるジャンプ / 水中で浮上 |
| `左クリック` | カーソル位置のブロックを1発破壊（穴を開けると水や溶岩が流れる） |
| `F` / `X` | 松明を置く / 近くの松明を回収 |
| `Q` / `E` または `ドラッグ` | カメラ回転・仰角変更 |
| `マウスホイール` | ズームイン / アウト |
| `R` | 初期位置へ戻る |

## 会話と開発のステップ（Neon との対話ログまとめ）

このプロジェクトは、あらかじめ仕様書を書いたわけではなく、**「ブラウザで動かして見た目や触り心地を確認 → 気になった点や次のアイデアを会話で伝える → 実装・改善してコミット」** というサイクルを19回以上回して育てていきました。

### Step 1: スプライトスタッキングの理解からスタート（`cd37c2d`）
- 最初に「スプライトスタッキングの仕組みを体感したい」というところから、シンプルなシューティングデモ（現在は `shooting/` に待避）と、草原・風揺れする木草の可視化パネルを作成。
- 続けて「この仕組みでマイクラのようなボクセル世界を歩き回れるプロトタイプも作ろう」と `voxel-walk/` を立ち上げました。

### Step 2: 3Dの立体感・キャラの顔・ブロック間の隙間解消（`acff4e6` → `ab3ae8a` → `b1cf258`）
- 見た目の細部を観察しながら、崖の露出エッジへの輪郭線・ベベルハイライト・標高シェーディングを追加。
- プレイヤーの目の配置を離して分かりやすく修正し、オーバーハング裏側に出ていた1スライス分の隙間を **「共有境界スライスに露出天面キャップを置く」** 方式で完全に密閉しました。

### Step 3: 64×64 地形とテラリア式・質量保存水流（`3ba61e9` → `8be8af5` → `ce602b2`）
- ノイズ地形と木を追加し、テラリア式の8段階（内部64段階）質量保存水流を実装。動的アクティブ落下BFSと単調流下ルールにより、振動ゼロ・100%質量保存・自動静止を達成。
- **「水面がただの白いぼかしに見えるので、水表面特有のノイズテクスチャにしてほしい」** → 周期 Worley / Voronoi コースティクスを導入し、**「もうちょっとおとなしく」** の調整で落ち着いた水面表現に仕上げました。

### Step 4: 128×128 岩山拡張 → Safari 13fps からの WebGL2 全面移行（`9125ab0` → `5779fe0`）
- **「岩山・オーバーハング・トンネルを含む激しいバイオームを追加し、描画統計を表示してマップを128×128に広げたい」** と拡張。
- 実機確認で **「Safariで13fpsしか出ない。水が安定するまで25fps、安定後55fps以上は欲しい。WebGL2にさっさと移行しよう」** となり、Canvas 2D から **WebGL2 インスタンシング描画（`TEXTURE_2D_ARRAY` + GLSL コースティクス）** へ全面移行。一気に軽量化しました。

### Step 5: スパゲッティ洞窟と透視カットアウトの試行錯誤（`52558cd` → `0c5e96d` → `68e0a2f`）
- **「スパゲッティ洞窟を生成し、プレイヤーが隠れたら遮蔽ブロックを輪郭線や半透明にしたい」** と実装。
- 初回は埋まった層すべてに輪郭を描いたため **「輪郭だらけでプレイヤーの周りがほとんどわからない」**（スクリーンショット共有）→ 露出した最外表面の屋根輪郭だけを残す方式へ修正。
- 続けて **「まだ隠れていないのに真上にブロックがあるだけで透視モードになる」**（スクリーンショット共有）→ 真上天井チェックを撤廃し、カメラ視線レイマーチ判定へ変更。さらに **「ちょっとでも隠れたらではなく、完全に隠れたら」** の要望に合わせて5点全遮蔽判定へ仕上げました。

### Step 6: 16ブロック光源・昼夜サイクル・松明・溶岩だまり（`60dd9de` → `6229bc0` → `d5a2372`）
- **「マイクラのように16ブロック届く光源を置きたい。昼夜で真っ暗になり、松明や溶岩（明るさ15）で周囲が照らされるように」** → 3D BFS の `skyLight / blockLight`（`TEXTURE_3D` `LINEAR` 補間）と昼夜サイクル、松明設置・回収、7か所の溶岩だまりを実装。
- プレイ感を試しながら **「夜を短くしてほしい」**（夜は2.5倍速・約14.5秒、昼は44秒）、**「時間は明け方から始まるように」**（05:30スタート）へ調整しました。

### Step 7: 木・雑草・花の「ブロックの形を崩さない」揺れ表現（`6229bc0` → `68e0a2f`）
- **「木が風で揺れ、プレイヤーが当たったらさらに大きく揺れるように」** を実装したところ、**「当たったときの揺れがサイン波みたいで気持ち悪い」「風が縦方向だけに見える」「ブロックの形が変わらずに、それぞれのブロックが違う方向に少し揺れるようにできる？」** と本質的なフィードバック。
- スライス毎のせん断変形を廃止し、**1ブロック（8スライス＋上面キャップ）丸ごと立方体の形を保ったまま `2×2` 近傍探索＋カメラ深度ソートで独立移動する剛体揺れ**へ刷新。主風向きも45°カメラで横〜斜めに映える方向へ修正しました。
- **「草ブロックの上に揺れる雑草と花を出してほしい」** → 実装後 **「草の色が地面と同じすぎて見えない・花の割合を1/3に」** の調整で、深緑の根元シャドウ＋明るい穂先と控えめな5色の野花に仕上げました。

### Step 8: 1×1×1 雲ブロック＆雲の影・山頂の泉・2段ジャンプ・ランダムシード（`d5a2372`）
- **「高さ20に東から西へ流れる雲と、その下に落ちる影を作りたい」** → 太陽光成分だけを涼やかな青みシャドウで落とす表現を設計。雲本体も **「霧っぽい→エッジがわかるもこもこ感強めに→大きさ1の雲ブロックが集まった感じに→雲を半分に→邪魔なのでもっと広く透かして」** と対話でブラッシュアップし、25スライス密積みの `1×1×1` 雲ブロック集合体＋プレイヤー周辺の広い単層フェード透過へ到達しました。
- 併せて **「山の上に泉を追加してずっと水が少しずつ湧き出すように」「2ブロックを1回のジャンプで登れるように」「毎回違う乱数シード＆泉をもう少し多く」** を反映し、6か所の山頂の泉を実装しました。

### Step 9: 「飛び飛びの水」を繋がる小川とリアルな滝へ（`23e5d53`）
- 山頂の泉のスクリーンショットから **「水が飛び飛びになっているのを流れる小川みたいに繋げたい」** → 毎ステップ定常湧出＋質量を変えずに流路を保つウェットトレイル＆段差の滝カーテン接続を導入。
- 続いて滝のスクリーンショットから **「滝の縞模様がワンパターンすぎる」** → 単一サイン波を撤廃し、ドメインワープ付き3層異速度縦スクロールノイズ＋外皮白泡＋滝壺しぶきへ刷新しました。

### Step 10: 松明の煙・フル画面化・白い羊モブ・クリック1発破壊（`1d9835b`）
- **「松明から風に流れていく煙を（もっと長く残って見えるように）」「右側のコントロール部分は全て不要」「白い羊モブを何匹か」「クリックしたらどんなブロックでも1発で穴を開けられ、水の流れがまた動くように（デブリなし）」** をまとめて実装。
- 右パネルと2Dプレビューを全削除してフル画面化し、10×10×9スライスの白い羊10匹、トップダウン・スライスレイキャストによる1発破壊＋局所3×3差分ベイク＋水流・3Dライト即時再計算を実現しました。

### Step 11: 25fps低下からのGPU高速化・GitHub Pages公開・流動溶岩（`b247c48` → `3deafd1` → `0b9d5fe`）
- フル画面化と機能追加で **「フレームレートが25fpsまで落ちた」** という報告を受け、プロファイルして3大ボトルネックを解消：
  1. 雲の Voronoi ドーム計算を `128×128` 周期テクスチャへ事前ベイク（毎フレーム Voronoi 計算ゼロ）
  2. 松明の煙探索に近傍マスクビットを導入（空中ピクセルの **99.993%** を即スキップ）
  3. 空中ピクセルでの巨大地形テクスチャ (`768×768×112`) 参照をスキップ
- **「GitHub Pagesに公開＋アプリ内からリポジトリへ飛べるリンク」** を追加して公開し、さらに **「溶岩がゆっくり流れるように」** の要望で粘性流動溶岩と動く16ブロック光源を実装しました。

### Step 12: 自動探索によるウォークスルー動画撮影・AI視聴字幕付け・YouTube公開
- **「自動で適当に探索するスクリプトを作って動画撮影して、最後にAI自身が動画を見てサブタイトルをつけられないか」** というアイデアから、撮影〜字幕付けパイプラインを構築しました：
  1. **自律探索＆フレーム精度録画**: Headless Chrome（Metal WebGL2）＋ CDP に仮想クロックを注入し、実際のキーボード（`WASD` / `Space` / `Q/E` / `F`）・左クリック破壊・ホイールズームを自律操作してコマ落ちゼロで `ffmpeg` へパイプ録画。Take 1 の映像を目視確認してズームアウト過多・崖引っかかりを発見し、地形を BFS で事前解析した歩行可能ルートへ改良して Take 2 を撮影。
  2. **AI 自身による動画視聴＆スプライトスタッキング解説字幕の生成**: 録画した MP4 を AI が全編確認し、画面上の時刻変化（明け方 `05:33` → 昼 → 夕焼け → 真っ暗な夜 `22:34`）と各イベントに合わせて字幕を設計。**「ゲーム説明よりスプライトスタッキング表現の工夫を多く宣伝してほしい」** の要望に合わせ、128層インスタンス描画・ブロック剛体揺れ・3×3差分再ベイク・AO焼き込み・3D-BFS光源など 12 シーンの技術解説字幕を作成しました。
  3. **ピクセルが潰れないフルHD高画質化**: **「画質が低いのでピクセルが潰れないように（ファイルは大きくてOK）」** を受け、`1280×720` JPEG キャプチャから **`1920×1080` フルHD・無劣化 PNG キャプチャ → `CRF 14`・`deblock=-1,-1` のワンパス字幕直焼き** へ刷新し、ドット境界のシャープさを維持。
  4. **YouTube 公開＆X ドラフト作成**: ブラウザ連携（Chrome リモートデバッグ）で YouTube Studio へアップロードし、デモ＆ソースコードへのリンク・技術チャプター付きで公開（https://youtu.be/7FPYQUXml3o）。あわせて過去ポストの文体を分析して X 向けの告知ドラフトも作成しました。
