# スプライトスタッキング・シューティング デモ

2D描画だけで立体（擬似3D / ボクセル風）を表現する **スプライトスタッキング (Sprite Stacking)** と、それを応用した **木や草の風揺れ表現** の仕組みを体感・理解するためのシューティングゲームデモです。

外部ライブラリやビルド環境は不要で、ブラウザだけで動作します。

## 起動方法

`index.html` をブラウザで直接開くだけで遊べます。  
（ローカルサーバーで開く場合は、このディレクトリで `python3 -m http.server 8000` を実行して `http://localhost:8000` にアクセスしてください。）

## 操作方法

- **移動**: `W` `A` `S` `D` または 矢印キー
- **照準・射撃**: マウス移動 + 左クリック（または `Space`）
- **カメラ回転**: `Q` / `E`
- **一時停止（観察モード）**: `P`（一時停止中も風とカメラ回転は動かせます）
- **リスタート**: `R`

## 仕組みを理解するためのおすすめの触り方

画面右側の **観察パネル** を操作すると、ゲーム画面と単体プレビューの両方にリアルタイム反映されます。

1. **「広葉樹」「針葉樹」「草むら」タブを選び、「風の強さ」を `強風 (2.2)` にする**
   - 根元 (`Z=0`) は地面に固定されたまま、上の層ほど大きく横へずらす (`bend = (z / maxZ)^1.8`) ことで、自然な「しなり」が生まれることが分かります。
2. **「スライス枠とZ軸」をON + スライス間隔を `6px (分解表示)` にする**
   - 青い点線のZ軸が風に合わせてしなり、各層の2Dスライスがその曲線に沿って並んでいる正体がひと目で見えます。
3. **草原の上を飛び回ったり、木に弾を撃ってみる**
   - 自機や敵が草むらを通過すると、草の先端レイヤーが外側に押し分けられてしなります。
   - 木の幹に弾が当たると木が大きく揺れて葉っぱが舞い落ちます。
4. **「▶ 1層ずつ積み上げ再生」** や **2Dスプライトシートのホバー確認**
   - 輪切りの2D画像が下から順に積み重なって立体になる過程と、各層の対応関係を確認できます。

## コード構成

- `js/models.js` — 各モデル（自機・敵・広葉樹・針葉樹・草むら・弾）の輪切り2Dドット絵データ
- `js/stackRenderer.js` — スプライトスタッキング＆しなり揺れ描画の核心部分（`drawStackedSprite` 関数）
- `js/game.js` — 自然な草原・小道テクスチャ生成、風の波シミュレーション、シューティング本体、観察パネル制御
- `index.html` / `style.css` — レイアウトとUI
