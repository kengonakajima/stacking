3. スプライトスタッキングの原理

3Dモデルを使わず、輪切りにした2D画像（スライス）を下の層から順に上へずらして回転描画します。 さらに木や草は高い層ほど横へずらす（しなり曲線）ことで、根元を固定したまま風で揺れる表現ができます。 

// js/stackRenderer.js の核心ループ
for (let z = 0; z < layers.length; z++) {
  const bend = Math.pow(z / maxZ, 1.8); // 上の層ほどしなる
  ctx.save();
  ctx.translate(
    x + swayX * bend,            // 風の揺れ（根元は0）
    y - z * spacing + swayY * bend
  );
  ctx.rotate(angle + swayTwist * bend);
  ctx.drawImage(layers[z], -w/2, -h/2, w, h);
  ctx.restore();
}
