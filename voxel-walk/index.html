3. ボクセル×スタッキングの仕組み

世界全体を高さごとの2D水平断面キャンバス（worldSlices[z]）に焼き込み、 下から1枚ずつ重ねて描画します。プレイヤーも同じ高さ z のタイミングで差し込むため、 丘の裏に隠れたり、橋の下をくぐったりしても前後関係が破綻しません。 

// js/renderer.js の核心ループ
for (let z = 0; z < maxSliceZ; z++) {
  // 1. 世界全体の高さ z の断面を1枚描画
  drawSlice(worldSlices[z], z);
  // 2. プレイヤーがその高さ z に居れば差し込む
  if (z >= playerMinZ && z <= playerMaxZ) {
    drawPlayerSlice(z - playerMinZ, z);
  }
}
