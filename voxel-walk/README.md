# Voxel Walk 128 (WebGL2) — スプライトスタッキング・ボクセルワールド

**WebGL2 インスタンシング描画（`TEXTURE_2D_ARRAY` ＋ `TEXTURE_3D` ライトマップ）** を用いたスプライトスタッキング・ボクセルワールドデモです。

## 特徴

- **Minecraft 式 3D 光源伝播エンジン（16ブロック到達・明るさ 0〜15）**
  - **太陽光 (`skyLight`)** と **ブロック光 (`blockLight`)** を 3D BFS で計算し、`128×128×14` の `TEXTURE_3D`（`LINEAR` 補間）で滑らかなスムースライティングを実現。
  - **昼夜サイクル**: 朝→昼→夕方→夜へと時間経過で空と太陽光が変化し、夜はほぼ真っ暗になります（スライダー＆プリセットで任意の時刻へ即時移動可能）。
  - **松明設置 (`F`) / 回収 (`X`)**: 明るさ 15 の松明を好きな場所へ設置でき、周囲 15〜16 ブロックを暖かく照らします（壁でしっかり遮光）。
  - **溶岩だまり (`BLOCK_LAVA`)**: 明るさ 15 の自己発光マグマだまりを洞窟内や岩山に複数生成。
- **スパゲッティ洞窟 ＋ 自動 X-Ray 透視**
  - 2つの 3D ノイズ交差でうねる地下スパゲッティ洞窟を生成。
  - 洞窟や崖の裏でプレイヤーが隠れると、外表面だけを残して自動で透視（`地形輪郭のみ` / `うっすら半透明` / `完全切り抜き`）。
- **テラリア式・総量保存の8段階水流（内部64段階＋スリープ）**
  - 動的落ち口 BFS により高所の水がすべて谷へ流れ落ちたあと完全静止。GLSL シェーダーで 60fps 連続の Worley/Voronoi コースティクスと岸辺のさざ波を描画。

## 操作方法

- `W` `A` `S` `D` / 矢印キー: 歩く・水中移動
- `Space`: ジャンプ / 水中で泳ぎ上がる
- `F`: 松明を置く（明るさ 15） / `X`: 近くの松明を回収
- 画面ドラッグ / `Q` `E`: 360°カメラ回転・仰角（Pitch）変更
- マウスホイール: ズーム / `R`: 初期位置に戻る
