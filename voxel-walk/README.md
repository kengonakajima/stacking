# Voxel Walk 128 (WebGL2) — スプライトスタッキング・ボクセルワールド

**WebGL2 インスタンシング描画（`TEXTURE_2D_ARRAY` ＋ `drawArraysInstanced`）** を用いたスプライトスタッキング・ボクセルワールドデモです。

## 特徴

- **WebGL2 インスタンシング・スプライトスタッキング**
  - 128×128×12（最大97層）の地形を 1枚の `TEXTURE_2D_ARRAY` に格納し、プレイヤーより下・上を各 1回の `drawArraysInstanced` で一括描画（全体で約 28〜38 ドローコール）。
  - 水データは `128×128×12` の `RG8` テクスチャ（393KB）の変更層だけ `texSubImage3D` で GPU 転送するため、**水が流れ落ちている最中でもフル解像度 (`1.0x`) で 60fps** を維持します。
  - フラグメントシェーダーで **60fps 連続アニメーションの Worley/Voronoi コースティクス網目** と **岸辺のさざ波ハイライト** をリアルタイム生成しています。
- **128×128×12 マルチバイオーム**
  - **森の渓谷バイオーム**: ノイズ起伏の草原・池・ボクセルの木。
  - **激しい岩山・峡谷バイオーム**: 岩ブロック・深岩ブロック・3Dノイズのオーバーハング（張り出し岩棚）・歩いて通り抜けられる大トンネル。
- **テラリア式・総量保存の8段階水流（内部64段階＋スリープ）**
  - 動的「有効落ち口」BFS と単調下り排水により、総量（`57,600` 単位）を1単位も増減させずに高所の水をすべて谷へ流し落とし、自動的に完全静止します。

## 操作方法

- `W` `A` `S` `D` / 矢印キー: 歩く・水中移動
- `Space`: ジャンプ / 水中で泳ぎ上がる
- 画面ドラッグ / `Q` `E`: 360°カメラ回転・仰角（Pitch）変更
- マウスホイール: ズーム
- `R`: 初期位置に戻る
