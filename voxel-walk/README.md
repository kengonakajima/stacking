# Voxel Walk — スプライトスタッキング・ボクセルワールド

スプライトスタッキング（2Dの水平スライスを高さ方向に重ねて描画する手法）を用いて、Minecraft風の3Dボクセル空間をウォークスルーできるプロトタイプです。

## 特徴

- **土ブロック (`BLOCK_DIRT`)** と **草ブロック (`BLOCK_GRASS`)** で構成された 20×20×6 の立体ボクセル地形
  - ゆるやかな丘・段差・土のくぼみ・**下をくぐれて上も歩ける立体アーチ橋**を配置
- **世界全体のスライス焼き込み方式 (`worldSlices[z]`)**
  - 3Dボクセル世界を高さごとの2D水平断面キャンバス群へ変換し、下から順に描画します。
  - プレイヤーも同じ高さ `z` のタイミングで差し込むため、丘の裏に隠れたり橋の下をくぐっても前後関係が正確に描画されます。
- **観察パネル付き**
  - 単体モデル（草ブロック / 土ブロック / プレイヤー）の2Dスライス分解表示
  - スライス間隔（0x平面 〜 2x分解）、高さカット（輪切り断面観察）、カメラ角度・仰角（Pitch）変更

## 起動方法

`index.html` をブラウザで直接開いて遊べます。

## 操作方法

- `W` `A` `S` `D` / 矢印キー: 歩く
- `Space`: ジャンプ（1段の段差を登る）
- 画面ドラッグ / `Q` `E`: 360°カメラ回転・仰角変更
- マウスホイール: ズーム
- `R`: 初期位置に戻る
