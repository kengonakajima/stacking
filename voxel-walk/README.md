# Voxel Walk 128 — スプライトスタッキング・ボクセルワールド

スプライトスタッキング（2Dの水平スライスを高さ方向に重ねて描画する手法）を用いて、**128×128×12** のマルチバイオーム地形（森の渓谷＋オーバーハングやトンネルを含む激しい岩山）とテラリア式水流をウォークスルーできるデモです。

## 特徴

- **128×128×12 のマルチバイオーム地形**
  - **森の渓谷バイオーム**: ノイズ起伏の草原・池・ボクセルの木（幹＋葉）。
  - **激しい岩山・峡谷バイオーム**: 岩ブロック・深岩ブロックで構成された切り立った尾根、3Dノイズで彫刻された**オーバーハング（張り出し岩棚）**や**歩いて通り抜けられるトンネル**。
- **テラリア式・総量保存の8段階水流（内部64段階＋スリープ）**
  - 内部64段階（表示8段階）の整数水量で総量を厳密に保存し、動的「有効落ち口」BFS で高所の水がすべて低い谷へ流れ落ちたあと自動的に完全静止（スリープ）します。
  - 中はほぼ透明（1層あたり約8%の深い青）、表面は周期 Worley/Voronoi セルラーノイズによる穏やかなコースティクス網目模様を描画します。
- **ビューポート・クロップ最適化＆リアルタイム描画統計**
  - 各スライス描画時に画面4隅を逆投影して可視矩形のみを `drawImage` クロップ描画。
  - 右パネルで **FPS / 描画時間(ms) / ドローコール数（地形・水・その他内訳）/ 描画スライス数 / 画面内クロップ面積 / 水流計算時間** をリアルタイム確認できます。

## 操作方法

- `W` `A` `S` `D` / 矢印キー: 歩く・水中移動
- `Space`: ジャンプ / 水中で泳ぎ上がる
- 画面ドラッグ / `Q` `E`: 360°カメラ回転・仰角（Pitch）変更
- マウスホイール: ズーム
- `R`: 初期位置に戻る
