# Voxel Walk — 64×64 スプライトスタッキング・ボクセルワールド

スプライトスタッキング（2Dの水平スライスを高さ方向に重ねて描画する手法）を用いて、64×64 のノイズ起伏地形・木・テラリア式の流れる半透明水をウォークスルーできるボクセルデモです。

## 特徴

- **64×64×10 のノイズ起伏地形＆ボクセルの木**
  - 多オクターブノイズで山・谷・盆地を生成し、土ブロック・草ブロック・木の幹・葉ブロックを立体配置。
  - 3D アンビエントオクルージョン（木陰・段差接地影・軒下影）＋段差エッジ強調＋境界天面キャップ（隙間ゼロ）を事前ベイク。
- **テラリア式・総量保存の8段階水流シミュレーション**
  - 各セルが整数 `0〜8`（1ブロック＝8スライスに 1対1 対応）の水量を保持し、重力落下と水平拡散で高所から低い谷へ流れ落ちて溜まります。
  - すべての移動で総量が厳密に保存され、右パネルで「水の総量（一定）」を確認できます。
  - 半透明スライスの重なりによって浅い水は透明感が高く、深い水ほど濃い青になり、露出水面にはスクロールする波紋アニメーションが合成されます。
- **ウォークスルー＆水中遊泳**
  - 木の下をくぐったり、浅瀬を歩いたり、深い池で `Space` を押して泳ぎ上がることができます。

## 起動方法

`index.html` をブラウザで直接開いて遊べます。

## 操作方法

- `W` `A` `S` `D` / 矢印キー: 歩く・水中移動
- `Space`: ジャンプ / 水中で泳ぎ上がる
- 画面ドラッグ / `Q` `E`: 360°カメラ回転・仰角（Pitch）変更
- マウスホイール: ズーム（全体俯瞰〜近接まで調整可能）
- `R`: 初期位置に戻る
